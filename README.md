# Task 4 – Sales Performance & Financial Analysis Dashboard

## Project Overview
This project was completed as part of the Data Analyst Internship – Task 4.

The objective is to design an interactive dashboard using Microsoft Power BI to analyze sales and financial performance and support business decision-making.

## Tools Used
- Microsoft Power BI
- Microsoft PowerPoint
- GitHub

## Dataset
- Dataset: Sample Superstore
- Source: Kaggle
- Records: 9,994
- Columns: 21

## Key Performance Indicators
- Total Sales
- Total Profit
- Total Orders
- Total Quantity

## Dashboard Visualizations
- Sales by Category
- Profit by Region
- Sales by Segment
- Monthly Sales Trend

## Interactive Features
- Region slicer
- Category slicer
- Order Date slicer

## Deliverables
- Interactive Power BI Dashboard (.pbix)
- PowerPoint Summary (.pptx)
- Dashboard Screenshot (.png)
- Dataset (.csv)

## Learning Outcome
Learned to design interactive dashboards, analyze business performance, identify sales trends and present insights to support business decisions.
